# M1 PR notes

## Security notes

- Outbound HTTP remains centralized in `tis.http` and is limited to the two approved hosts.
- Redirect targets are checked before following them.
- Dry run remains enabled by default and cannot be disabled in development.
- External writes are guarded by kill switch, idempotency, and per-run/per-day budgets.
- Logs omit request and response bodies and redact sensitive headers, query values, and PII.

## Open questions

None. Rehaan supplied the authoritative redacted `integration_log` and `integration_state`
contracts on the G0 PR.

## Deviations from plan

The supplied contract described the Supabase REST `Prefer: resolution=merge-duplicates` header.
M1 uses the approved Psycopg connection and its equivalent parameterized PostgreSQL
`ON CONFLICT (source, external_id, action) DO UPDATE`; no Supabase REST host was approved or added.
