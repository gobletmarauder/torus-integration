# M2 PR notes

## Security notes

- Zoho writes use `@external_write` with `(zoho, Supabase UUID, upsert_lead)`, the existing kill switch, dry run, budgets, and atomic audit claim.
- The exact egress additions are `accounts.zoho.com` and `www.zohoapis.com`; runtime and static guard lists remain identical.
- Credentials are `SecretStr` settings populated only by the SOPS-managed runtime environment. Bodies, credentials, Authorization headers, names, and email local parts are never logged.
- SQL is fixed and parameterized. Work is ordered, capped at 25, and selected with `FOR UPDATE SKIP LOCKED`.
- Tests contain only synthetic values and intercept all HTTP.
