## Security notes

M5 treats the target as a shared production host. Bootstrap does not alter inbound-network or
remote-login configuration, does not restart Docker, preserves the discovered Docker data root,
and creates only torus-prefixed resources. Production ciphertext and keys were not created, read,
decrypted, or committed by Codex.
